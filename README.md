# 수능영어 AI과외 (Windows 판)

수능 영어 공부를 위한 **무료** Windows 프로그램입니다. 인터넷 연결 없이 모든 기능을 쓸 수 있습니다.

- **문장**: 독해력 증진(짧은·중단·장문 × 하·중·상), 수능 풀이(안내문·전기문·이야기·학술문 2,400지문)
  단어를 길게 누르면 그 문장의 해석, 사전, 듣기
- **듣기**: 수능 듣기 16문항 묶음, 유형별 듣기 학습 (컴퓨터 음성)
- **단어장**: 영한·한영 사전, 단어장 저장, 숙어·구동사, 불규칙 동사 표
- **문법**: 기초 문법 · 정석 문법 · 점프, 유닛별 설명과 연습문제

## 내려받기

👉 **[최신 버전 내려받기 (Releases)](../../releases/latest)** 에서 `수능영어AI과외_설치_x.x.exe` 를 받으세요.

- Windows 10 / 11 (64비트)
- 관리자 권한 없이 설치됩니다.
- 설치 첫 화면의 **사용 조건**에 동의해야 설치됩니다. (상업적 이용 금지)

## 설치할 때 보이는 경고에 대해

이 프로그램은 개인이 무료로 만든 것이라 유료 코드 서명 인증서가 없습니다. 그래서 처음 실행할 때
**"Windows의 PC 보호"** 창이 뜰 수 있습니다. **추가 정보 → 실행**을 누르면 설치됩니다.

내려받은 파일이 이 페이지의 파일과 같은지는 아래 명령으로 확인할 수 있습니다.
값이 릴리스 설명의 **SHA-256** 과 같으면 변조되지 않은 파일입니다.

```
Get-FileHash .\수능영어AI과외_설치_1.0.exe -Algorithm SHA256
```

## 음성이 나오지 않을 때

**설정 → 시간 및 언어 → 음성**에서 영어(미국) 음성과 한국어 음성을 추가하세요.

## 개인정보

이 프로그램은 인터넷에 접속하지 않으며 개인정보를 수집하지 않습니다.
단어장과 학습 기록은 내 컴퓨터(`%APPDATA%\EduEnglish`)에만 저장됩니다.
